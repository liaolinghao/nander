# WEB构件

本构件用于统一WEB框架，该框架包括八大模块：

核心模块：提供不涉及任何中间件操作的WEB工程框架。

WS模块：提供不涉及任何中间件操作的WEB SOCKET工程框架。

持久模块：提供涉及数据持久化操作过程中统一异常响应的WEB工程框架，依赖核心模块。

网络模块：提供涉及调用外部Rest接口的签名处理器，依赖核心模块。

安防模块：提供支持对外开放接口的WEB工程框架，依赖核心模块和持久模块。

频控模块：提供支持各种维度的频率控制的WEB工程框架，依赖核心模块。

调度模块：提供任务调度服务的WEB工程框架，依赖持久模块。

验证码模块：提供支持各类验证码接口的WEB工程框架，依赖核心模块和频控模块。

授权模块：提供支持JWT登录认证的WEB工程框架，依赖核心模块。

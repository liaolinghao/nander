# WEB构件安防模块

本构件属于统一WEB框架的安防模块，提供以下功能：

1、设计一套接口防御机制，可支持：防重放攻击，接口签名校验，IP白名单校验，接口数据自动加解密等。

接口请求流程：客户端请求 → 过滤器（Filter）→ 拦截器（preHandle）→ Controller 方法 → 拦截器（postHandle）→ 过滤器（响应阶段）→ 客户端

前提条件：采用过滤器包装请求对象与响应对象，以支持缓存能力。

执行原理：先采用加解密拦截器完成请求数据自动解密与响应数据自动加密（加解密根据调用方身份进行差异化处理），再采用防御拦截器（对方法加上注解@Defenceless可消除防御机制）判断接口请求是否放行。

加解密机制：对接口请求支持字段级加解密或者数据包级加解密，其中，字段级加解密根据请求字段是否在关键字段库内进行判断。备注：目前不支持form表单模式的接口请求。

签名要点：采用签名算法计算签名时需要采用解密后的数据执行运算。

2、为使动态接口安全管理数据库更为聚焦，在引入接口安全管理模块时需要单独划分一个数据库用于组织相关数据表并且将该数据源冠以defence为标识。

接口：可以配置单个接口是否支持数据自动加解密。

调用方：可以配置调用方调用接口时采用的加解密机制，公钥与私钥对采用RsaKeyBits.KEY_512密钥长度生成。

## 配置

本构件配置描述如下：

### 用于接口防护

```
bigbird:
  server:
    web:
      defence:
        # 配置需要防护的接口模式，多个模式以英文逗号分隔
        patterns: /health/**,/common/**,/captcha/sms
        # 配置需要加解密处理的关键字段名称库（禁止配置code,msg,data三个敏感词），多个以英文逗号分隔
        keyFields: name,address
```

## 构件依赖

日志组件、Redis构件、MybatisPlus构件、缓存构件。

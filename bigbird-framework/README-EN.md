## 📚 Introduction

Java microservice component library covering various technologies involved in Java microservice architecture. It categorizes common functions required in microservice development into three dimensions by complexity, and organizes them separately according to functional categories.

-------------------------------------------------------------------------------

## 🛠️ Module

| Module                |     Description                                                                          |
|--------------------|---------------------------------------------------------------------------------- |
| bigbird-framework-core（CORE）          |     Basic Toolkit, including: string processing, data format processing, sorters, file processing, numeric processing, date & time processing, encoding processing, image processing, paginators, perpetual motion task executor, etc.|
| bigbird-framework-common（COMMON）      |     General Component Library, including: encryption & decryption component, GIS component, sensitive word filtering component, logging component, data desensitization component.|
| bigbird-framework-data（DATA）          |     Data Components, including Elasticsearch component, Kafka component, MyBatis-Plus component, MongoDB component, Redis component, RabbitMQ component, RocketMQ component, Zookeeper component and OSS component.|
| bigbird-framework-cache（CACHE）        |     Cache Components, including distributed cache and local cache.|
| bigbird-framework-distributedlock（DL） |     Distributed Lock Components, including ZooKeeper lock and Redis lock.|
| bigbird-framework-document（DOC）       |     Document Components, including Excel generation, PDF generation, Word generation and HTML generation.|
| bigbird-framework-message（MESSAGE）    |     Message Components, including SMS, Email, DingTalk and WeCom.|
| bigbird-framework-id（ID）              |     ID Components, including twitter-snowflake、leaf-segment、baidu-uid.|
| bigbird-framework-server（SERVER）      |     Service Framework Components, including web framework for general web APIs, web framework for interface security protection, web framework for JWT authentication, web framework for rate limiting, web framework for verification code service, web framework for external API invocation, web framework for dynamic job scheduling, and WebSocket service framework.|
| bigbird-framework-plugin（PLUGIN）      |     Plugin Library, including MyBatis-Plus code generation plugin.|
| bigbird-framework-parent               |     Defines common dependencies for all the above components.|
| bigbird-framework-dependencies         |     Defines the dependency versions for all the above components.|

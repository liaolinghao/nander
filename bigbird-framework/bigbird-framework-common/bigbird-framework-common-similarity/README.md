# 相似度计算组件

本组件用于文本相似度计算，提供如下类型服务：

## 一、服务能力概览

| 服务类型 | 支持策略 |
|---|---|
| 词语相似度计算 | 词林相似度、知网概念相似度、拼音相似度、字面相似度 |
| 短语相似度计算 | 莱文斯坦归一化相似度、JaroWinkler 短字符串优化相似度、Trigram 杰卡德相似度、余弦相似度 |
| 语句相似度计算 | 语义相似度 |
| 段落相似度计算 | 待补充 |

## 二、词语相似度计算

词语相似度计算支持以下四种策略：

| 策略 | 说明 | 适用场景 | 
|---|---|---|
| 词林相似度 | 基于词林语义体系计算词语相似度 | 适用于语义相关的词语比较，轻量、快速、实现简单、结果稳定可解释，但是粒度粗、无法处理未登录词、同码内不区分，适合大规模召回、粗筛、同义/近义词快速判断的场景 |
| 知网概念相似度 | 基于知网概念体系计算词语相似度 | 适用于语义相关的词语比较，语义粒度细、能处理未登录词、刻画深层语义，但是计算重、依赖大数据文件、参数（β/阈值）需调优，适合精排、深度语义匹配、对新词鲁棒性要求高的场景 |
| 拼音相似度 | 基于拼音计算词语相似度 | 适用于拼音相同的词语比较，适合同音字、近音字、多音字比较的场景 |
| 字面相似度 | 基于字符层面计算词语相似度 | 适用于字符级别的比较，适合错别字、部分字符重合、短词语匹配、名称近似判断等场景 |

### 2.1 词林相似度策略说明

词林相似度策略采用以下计算方式：

1. 获取两个词语在哈工大词林扩展版中的编码集合（一个词可能有多个编码，对应其多个义项）；
2. 对编码集合中的编码组合逐层比较，计算共同前缀的加权和（6 个层级权重依次为 1.2、1.2、1.0、1.0、0.8、0.4，从第 1 层起逐层比对，遇到首个不同层级即停止累加）；
3. 对共同前缀权重和进行归一化（归一化为相似度计算公式：similarity = 共同前缀权重和 / 总权重 5.6）；
4. 取所有编码组合中的最大相似度。

该策略适合基于语义体系的近义词、同义词、多义词场景下的中文语义匹配，常见于：中文语义相似度计算；同义词 / 近义词识别；文本查重与语义去重；智能客服问句匹配、意图识别；搜索召回中的语义扩展与排序。

### 2.2 知网概念相似度策略说明

知网概念相似度策略采用以下计算方式：

1. 获取两个词语在知网（HowNet）中的概念集合（一个词可能对应多个概念，每个概念由主义原、第二基本义原、符号义原、关系义原共同定义）；
2. 对概念集合中的概念组合逐一计算相似度，义原（Sememe）层面的相似度由 SememeSimilarity 按义原树层次结构计算；
3. 概念相似度按四项加权求和归一化（计算公式：similarity = β₁·sim₁ + β₂·sim₁·sim₂ + β₃·sim₁·sim₃ + β₄·sim₁·sim₄，其中 sim₁ 为主义原相似度，sim₂/sim₃/sim₄ 分别为其他义原集合的相似度，β 为各项权重）；
4. 取所有概念组合中的最大相似度，等于 1.0 时提前结束。

该策略适合基于义原语义体系的深度语义匹配，常见于：中文语义相似度计算；近义词 / 相关词识别；文本语义查重与去重；智能客服问句匹配、意图识别；知识图谱实体对齐与语义检索。

### 2.3 拼音相似度策略说明

拼音相似度策略采用以下计算方式：

1. 获取两个词语的多音字拼音集合；
2. 对拼音集合中的读音组合计算编辑距离（标准 Levenshtein 编辑距离：把一个拼音串变成另一个所需的最少插入、删除、替换次数。）；
3. 对编辑距离进行归一化（编辑距离归一化为相似度计算公式：similarity = 1 − distance/max(len1,len2)）；
4. 取所有读音组合中的最大相似度。

该策略适合同音字、近音字、多音字场景下的中文模糊匹配，常见于：中文模糊搜索、搜索建议；姓名匹配、通讯录去重；错别字/同音字纠错；地址、机构名等拼音近似匹配；IM 系统中按拼音搜索群组名、成员名。

### 2.4 字面相似度策略说明

字面相似度策略采用以下计算方式：

1. 统计两个词语中共同出现的字符，得到相同字符集合；
2. 计算字符重叠度：相同字符数量分别除以两个词语长度后取平均（0.5 × (sameChars/target + sameChars/candidate)）；
3. 计算长度系数：取两个词语长度比的较小值，即 min(target/candidate, candidate/target)，长度越接近系数越接近 1；
4. 计算位置权重平均分：对每个词语，按字符位置从前往后赋予递增权重 i + 1，统计相同字符所在位置的权重和占全部位置权重和的比例，相同字符出现越靠后得分越高；两个词语的位置权重得分再取平均；
5. 按权重合成最终相似度（相似度 = 0.6 × 字符重叠度 + 0.4 × 长度系数 × 位置权重平均分）。

该策略适用于字符级别的比较，常见于：错别字、部分字符重合、短词语匹配、名称近似判断等场景，其特点是实现简单、计算开销小，对字符重合较敏感，但该策略不区分字符顺序，例如“上海”与“海上”在字符层面会被判为高度相似。

## 三、短语相似度计算

短语相似度计算支持以下四种策略：

| 策略 | 说明 | 适用场景 | 
|---|---|---|
| 莱文斯坦归一化相似度 | 基于莱文斯坦编辑距离计算短语相似度 | 适用于短短语、名称、编号类文本，适合错别字、少量字符改动、简单变体匹配；计算极快，可解释强；缺点是不理解语义、语序敏感，长文本性能下降，不擅长同义词匹配 |
| JaroWinkler 短字符串优化相似度 | 基于 Jaro 相似度并针对短字符串前缀特征进行加权优化计算短语相似度 | 专门优化人名、地址片段、短编码、短语前缀近似场景；对开头相同的短语更友好；适合证件名称、商户简称、短标签匹配；不适合长文本、语序调换、纯语义同义场景 |
| Trigram 杰卡德相似度 | 基于字符三元组集合交并比计算短语相似度 | 工业短语模糊匹配常用方案，适合商品标题、地址、机构名称、长一点的短语模糊匹配；容错性优于单纯编辑距离；属于字面匹配，无语义能力 |
| 余弦相似度 | 基于文本向量化后的向量夹角计算短语相似度 | 适合具有一定词量、语义方向可比的短语与短文本匹配；对词序不敏感，能借助 TF-IDF 权重弱化高频词干扰，配合词嵌入可覆盖同义、近义表达；计算较快、易于批量处理；缺点是对分词质量依赖较强，词频向量难以区分词语位置与搭配，稀疏短句区分度有限，纯字面变体（错别字、编号改动）不如编辑距离类策略敏感 |

### 3.1 莱文斯坦归一化相似度策略说明

莱文斯坦归一化相似度策略采用以下计算方式：

1. 计算两个字符串之间的莱文斯坦编辑距离，即通过插入、删除、替换三种操作将其中一个字符串转换为另一个字符串所需的最少单字符操作次数；
2. 对编辑距离进行归一化处理，以消除字符串长度对相似度的影响，归一化相似度计算公式为：similarity = 1 − 编辑距离 / 两个字符串中的较长长度；
3. 相似度取值范围为 0 到 1，值越接近 1 表示两个字符串越相似，值越接近 0 表示差异越大。

该策略适合基于字符级编辑操作的拼写纠错、变体识别与短文本模糊匹配场景，常见于：中文错别字识别与纠正；人名、地名等实体拼写变体匹配；OCR 识别结果校对；搜索查询中的拼写容错与候选召回。

### 3.2 JaroWinkler 短字符串优化相似度策略说明

JaroWinkler 短字符串优化相似度策略采用以下计算方式：

1. 计算两个字符串的 Jaro 相似度：先确定匹配字符数 m（两字符相等且位置偏移不超过匹配窗口阈值），再统计换位字符数 t，Jaro 相似度 = (m/|s₁| + m/|s₂| + (m−t)/m) / 3；
2. 在 Jaro 相似度基础上施加前缀奖励：取两个字符串最长公共前缀长度 l（上限为 4），乘以缩放因子 p（默认取 0.1），对 Jaro 相似度进行增量修正，公式为：JW = Jaro + l × p × (1 − Jaro)；
3. 计算结果取值范围为 0 到 1，公共前缀越长，相似度得分越高。

该策略适合短字符串且前缀信息具有区分意义的匹配场景，常见于：人名、品牌名、商品标题等短文本相似匹配；智能客服中的短问句聚类与去重；数据清洗中的实体名称对齐；输入纠错与候选推荐。

### 3.3 Trigram 杰卡德相似度策略说明

Trigram 杰卡德相似度策略采用以下计算方式：

1. 将两个字符串分别转换为字符三元组集合（trigram）：以长度为 3 的滑动窗口逐字符截取；
2. 计算两个 trigram 集合的交集大小与并集大小，杰卡德相似度 = |交集| / |并集|；
3. 相似度取值范围为 0 到 1，交集占比越高表示两个字符串在字符片段层面的重叠程度越大。

该策略适合对局部字符片段重叠敏感、且对词序变化不敏感的模糊匹配场景，常见于：短文本查重与近似去重；商品标题、公司名称的模糊检索；拼写容错与部分匹配召回；多语言混合文本的粗粒度相似度筛选。

### 3.4 余弦相似度策略说明

余弦相似度策略采用以下计算方式：

1. 将两个文本分别进行分词与向量化表示，把每个文本转换为一个特征向量（如词频向量、TF-IDF 向量或词嵌入向量），向量各维度对应词汇表或语义空间中的特征维度；
2. 计算两个向量之间的余弦夹角，余弦相似度计算公式为：similarity = (A · B) / (‖A‖ × ‖B‖)，其中 A · B 为两向量的点积，‖A‖、‖B‖ 分别为两向量的模长；
3. 相似度取值范围为 −1 到 1，在非负特征向量场景下通常为 0 到 1，值越接近 1 表示两个文本的语义方向越一致、相似度越高。

该策略适合基于向量空间模型的整体语义方向比对场景，常见于：长文本语义相似度计算与文本聚类；文档查重与主题相近度判定；智能客服问句匹配与意图识别；搜索召回中的语义排序与相似内容推荐。

## 四、语句相似度计算

语句相似度计算支持以下策略：

| 策略 | 说明 | 适用场景 | 
|---|---|---|
| 语义相似度 | 基于词形（词面匹配） 与词序（逆序关系）计算语句相似度 | 适用于语义相关的词语比较，轻量、快速、实现简单、结果稳定可解释，但是粒度粗、无法处理未登录词、同码内不区分，适合大规模召回、粗筛、同义/近义词快速判断的场景 |

### 4.1 语义相似度策略说明

语义相似度策略采用以下计算方式：

1. 对两个句子分别进行分词与清洗，仅保留承载语义的有效词语，并过滤掉无实际意义的成分；若语句清洗后无有效词，则相似度直接记为 0；
2. 以知网（HowNet）概念相似度为基础，对目标句与候选句中的每一对词语逐一打分，构建词对相似度矩阵；再按相似度从高到低进行贪心最大匹配，使每个词最多参与一次匹配，并累加所匹配词对的相似度，得到词形相似度：wordSim = 2 × 匹配词对相似度之和 / (目标句词数 + 候选句词数)；
3. 在词形相似度之外引入词序相似度：将相似度不低于阈值（0.6）的词对视作“相同词”，按候选句词序记录其在目标句中对应的位置序列，统计该序列中相邻位置的逆序次数，并以 1 − 逆序次数 / (有效匹配词数 − 1) 进行归一化，得到词序相似度 ordSim；
4. 将词形相似度与词序相似度按权重加权融合，得到最终相似度：similarity = 0.8 × wordSim + 0.2 × ordSim；
5. 相似度取值范围为 0 到 1，值越接近 1 表示两个句子在语义与语序上越一致，值越接近 0 表示语义差异越大。

该策略适合在词语层面存在同义、近义或表述差异，但整体语义与语序基本一致的语句级模糊匹配场景，常见于：同义改写问句的识别与合并；FAQ 问答库中的语义召回与候选排序；客服话术、用户意图的语义归类；短文本去重与聚类；跨表述的标题、摘要相似度比对。

# 相似度计算组件

本组件用于文本相似度计算，提供如下类型服务：

## 一、服务能力概览

| 服务类型 | 支持策略 |
|---|---|
| 词语相似度计算 | 词林相似度、知网概念相似度、拼音相似度、字面相似度 |
| 短语相似度计算 | 莱文斯坦归一化相似度 |
| 句子相似度计算 | 待补充 |
| 段落相似度计算 | 待补充 |

## 二、词语相似度计算

词语相似度计算支持以下四种策略：

| 策略 | 说明 | 适用场景 | 
|---|---|---|
| 词林相似度 | 基于词林语义体系计算词语相似度 | 适用于语义相关的词语比较，轻量、快速、实现简单、结果稳定可解释，但是粒度粗、无法处理未登录词、同码内不区分，适合大规模召回、粗筛、同义/近义词快速判断的场景 |
| 知网概念相似度 | 基于知网概念体系计算词语相似度 | 适用于语义相关的词语比较，语义粒度细、能处理未登录词、刻画深层语义，但是计算重、依赖大数据文件、参数（β/阈值）需调优，适合精排、深度语义匹配、对新词鲁棒性要求高的场景 |
| 拼音相似度 | 基于拼音计算相似度 | 适用于拼音相同的词语比较，适合同音字、近音字、多音字比较的场景 |
| 字面相似度 | 基于字符层面计算词语相似度 | 适用于字符级别的比较，适合错别字、部分字符重合、短词语匹配、名称近似判断等场景 |

### 2.1 词林相似度策略说明

词林相似度策略采用以下计算方式：

1. 获取两个词语在哈工大词林扩展版中的编码集合（一个词可能有多个编码，对应其多个义项）；
2. 对编码集合中的编码组合逐层比较，计算共同前缀的加权和（6 个层级权重依次为 1.2、1.2、1.0、1.0、0.8、0.4，从第 1 层起逐层比对，遇到首个不同层级即停止累加）；
3. 对共同前缀权重和进行归一化（归一化为相似度计算公式：similarity = 共同前缀权重和 / 总权重 5.6）；
4. 取所有编码组合中的最大相似度。

该策略适合基于语义体系的近义词、同义词、多义词场景下的中文语义匹配，常见于：中文语义相似度计算；同义词 / 近义词识别；文本查重与语义去重；智能客服问句匹配、意图识别；搜索召回中的语义扩展与排序。

### 2.2 知网概念相似度策略说明

知网概念相似度策略采用以下计算方式：

1. 获取两个词语在知网（HowNet）中的概念集合（一个词可能对应多个概念，每个概念由主义原、第二基本义原、符号义原、关系义原共同定义）；
2. 对概念集合中的概念组合逐一计算相似度，义原（Sememe）层面的相似度由 SememeSimilarity 按义原树层次结构计算；
3. 概念相似度按四项加权求和归一化（计算公式：similarity = β₁·sim₁ + β₂·sim₁·sim₂ + β₃·sim₁·sim₃ + β₄·sim₁·sim₄，其中 sim₁ 为主义原相似度，sim₂/sim₃/sim₄ 分别为其他义原集合的相似度，β 为各项权重）；
4. 取所有概念组合中的最大相似度，等于 1.0 时提前结束。

该策略适合基于义原语义体系的深度语义匹配，常见于：中文语义相似度计算；近义词 / 相关词识别；文本语义查重与去重；智能客服问句匹配、意图识别；知识图谱实体对齐与语义检索。

### 2.3 拼音相似度策略说明

拼音相似度策略采用以下计算方式：

1. 获取两个词语的多音字拼音集合；
2. 对拼音集合中的读音组合计算编辑距离（标准 Levenshtein 编辑距离：把一个拼音串变成另一个所需的最少插入、删除、替换次数。）；
3. 对编辑距离进行归一化（编辑距离归一化为相似度计算公式：similarity = 1 − distance/max(len1,len2)）；
4. 取所有读音组合中的最大相似度。

该策略适合同音字、近音字、多音字场景下的中文模糊匹配，常见于：中文模糊搜索、搜索建议；姓名匹配、通讯录去重；错别字/同音字纠错；地址、机构名等拼音近似匹配；IM 系统中按拼音搜索群组名、成员名。

### 2.4 字面相似度策略说明

字面相似度策略采用以下计算方式：

1. 统计两个词语中共同出现的字符，得到相同字符集合；
2. 计算字符重叠度：相同字符数量分别除以两个词语长度后取平均（0.5 × (sameChars/target + sameChars/candidate)）；
3. 计算长度系数：取两个词语长度比的较小值，即 min(target/candidate, candidate/target)，长度越接近系数越接近 1；
4. 计算位置权重平均分：对每个词语，按字符位置从前往后赋予递增权重 i + 1，统计相同字符所在位置的权重和占全部位置权重和的比例，相同字符出现越靠后得分越高；两个词语的位置权重得分再取平均；
5. 按权重合成最终相似度（相似度 = 0.6 × 字符重叠度 + 0.4 × 长度系数 × 位置权重平均分）。

该策略适用于字符级别的比较，常见于：错别字、部分字符重合、短词语匹配、名称近似判断等场景，其特点是实现简单、计算开销小，对字符重合较敏感，但该策略不区分字符顺序，例如“上海”与“海上”在字符层面会被判为高度相似。
